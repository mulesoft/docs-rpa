// == What's New
include::partial$release-notes/rn-headings.adoc[tag=whatsNew,leveloffset=+1]

* You can now enable detailed debug logging in the trace log during execution without manually editing the configuration.
+
To enable this feature, go to *Settings Action Steps* → *Error Handling Settings*.
* The Tomcat dependency is upgraded to version 9.0.115 to address reported security vulnerabilities.
